# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through
[GitHub Security Advisories](https://github.com/MQ-xz/QuickSearchAdvanced/security/advisories/new).

Include a description of the vulnerability, affected versions or commits,
steps to reproduce, and the potential impact.

Please do not disclose vulnerabilities in public issues or pull requests.
Use the private advisory to discuss the report and coordinate disclosure.
